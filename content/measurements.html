Once I could see RoPE as a collection of waves, I wanted to know how a trained model was using the pieces. Were most angles doing important work? Or could some of them be stored much more crudely?

Every two-dimensional key pair has a radius and a phase. The radius says how long the arrow is; the phase says which way it points. If the arrow is very short, changing its direction moves its tip only a little. That made small-radius pairs an interesting place to start.

These plots suggest what to test, but they cannot tell us what the model needs. An apparently unstructured direction might still carry useful information. So the next step was to change the phases and run the model again.

Eight directions, four directions, or just one?

We kept each selected key pair’s radius and rounded its phase. Three phase bits leave eight directions, spaced by π/4. Two bits leave four directions, spaced by π/2. Zero bits leave one direction: every selected arrow points along the positive horizontal axis.

That last operation is stronger than rounding. A key at any angle is moved to \((r,0)\). It is also different from deleting the arrow, which would set its radius to zero.

For the small slow pairs, three-bit rounding had a much smaller effect than collapsing their phases to one direction. Across 7,168 predictions, it changed about 3.19% of top-one choices and increased mean loss by 0.00170 nats per token. Zero phase bits changed about 29.30% of choices and increased loss by 0.26280.

The difference answers a useful question: these small phases can tolerate coarse choices, but they are not simply unused. Keeping a few directions matters.

A related test across all frequency pairs

On sixteen shorter passages, three-bit phase rounding was applied across all 64 pairs only when actual key radius was below 2.5. It selected 75.71% of pair instances. A distinction that changed the interpretation

There had been a much more forgiving result earlier: some slow key biases could be simplified with almost no effect. It would have been easy to carry that result over to actual keys. The later experiment showed why we should not.

A key contains an input-dependent projection as well as a learned bias. Changing the constant bias changes only one part of that key. Rounding the phase of the whole key changes the actual arrow used for matching.

On the shorter 2,251-target test, rounding slow key-bias phases to four directions changed no top-one predictions. Removing small slow bias vectors changed just one. Those are interesting simplifications of the bias. They do not mean that actual slow keys need no phase information.

Turning the idea into compression was another test

So far, the experiment rounded angles while preserving radii. A complete codec must also store the radii, identify which pairs use fewer bits, and carry any decoding information. Once we counted those costs and quantized amplitudes too, the comparison became less favorable.

The three-bit shortcut gave useful compression, but it lost more quality than an earlier centered codec at almost the same storage cost.

Centering explains part of the difference. Imagine a key pair at \((10,1)\), close to a typical center \((10,0)\). Encoding the whole key means storing an arrow that points almost horizontally. Encoding its deviation means storing \((0,1)\), which points straight up. The same number of phase bits has a different meaning in those two coordinate systems.

Did we find mostly “positive” angles?

Another early question was whether the model mainly used alignment, with little use of opposition. Here the definition of “angle” turned out to matter.

A key’s direction by itself does not tell us whether it helps or hurts a score. It has to be compared with a query, after the positional rotation. And if we study the difference between the best and second-best key, we get yet another angle: one describing a query against a key contrast.

Negative contributions were common in this decomposition. Only 43.80% of the counted pair contributions were positive, although positive contributions accounted for 57.38% of available amplitude. So I would not carry forward a general claim that angles beyond π/2 are rare.

That does not turn the picture into a census of suppression mechanisms. We selected the winner using the full score, and then decomposed its margin. Some components help it win; others work against it. The useful lesson is that the head’s behavior belongs to the sum, not to one angle read in isolation.

By this point, the questions about compression had led back to attention itself. Which keys actually receive the mass of that mixture—and how does it change with distance?
