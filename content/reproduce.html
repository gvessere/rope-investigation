Original figures, inspectable measurements, and small portable programs that check the algebra and replay the reported numbers.

Run locally

git clone https://github.com/gvessere/rope-investigation.git
cd rope-investigation
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m unittest discover -s tests -v
python code/audit.py
python code/figures.py
npm ci
npm run build
npm run preview

The replay needs no model download. The site build renders equations to native MathML. Published pages need no external math service or web fonts; use a current browser with MathML support.

What is checked

  • Direct rotations equal the sinusoidal expansion, including its sine sign.
  • Phase rounding preserves radii, handles the circular seam, and leaves unselected pairs unchanged.
  • The complete DFT reconstructs arbitrary sampled data; a restricted RoPE basis generally does not.
  • Softmax shift invariance and its first-order output perturbation agree with numerical checks.
  • Binned fits recover known power-law exponents with exposure correction.
  • SHA-256 hashes match every original asset; per-token outputs replay the saved loss and prediction aggregates.
  • Dense attention arrays reproduce the decay exponents and 101/333 count.
  • Frozen vectors reconstruct all four engineered score profiles.

These are numerical replay and algebra checks. They are not a new full-model replication, a runtime benchmark, or evidence from a fresh model or corpus.

Regenerate every displayed figure

Run python code/figures.py. All 11 figures displayed in the blog are regenerated using the posted numeric plot inputs or explicit mathematical definitions. The original PNGs remain untouched. Outputs go to generated_figures/; the recipe manifest maps every image to its inputs, code, and function.

This recreates the charts from archived measurements, rather than rerunning Qwen inference. The provided source performs no hidden downloads and uses no private workspace files. Font rendering, plot layout, and raster bytes may vary across library versions and platforms. Frozen construction queries are recomputed from their native vectors and checked against the archive.

Original experiments and provenance

The archival scripts preserve the original experiment implementations. They depend on the original research workspace, model cache, captured activations, passage metadata, and Apple MPS setup. They are historical source, not portable entry points. The tested replay is separate.

Recovered PNGs are copied byte for byte; provenance.json records source-relative paths and hashes. Model weights and source book passages are not distributed. Numeric predictions, losses, and processed arrays support the replay.

A new full-model replication still requires pinned model/tokenizer revisions, recorded library versions and device, redistributable evaluation passages, Qwen split-half pairing, and baseline/identity controls. The recovered summaries do not establish a complete immutable environment.

What would strengthen the claims?

Evaluate untouched passages and additional models, test rare long-range retrieval, compare codecs at matched total bytes, and benchmark actual packed decoding. For phase statistics, define the relative angle before counting suppression. For decay, compare alternative tail models and intervene on frequency contributions rather than attributing a fitted slope to RoPE alone.
