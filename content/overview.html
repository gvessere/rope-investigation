Word order changes meaning. Positional encodings give attention a way to distinguish where information occurs; rotary embeddings make that information part of the query–key comparison.

These notes start with the geometry and then ask a less familiar question: what shapes can an attention head build as a function of position? The answer is useful for understanding both retrieval and compression.

Why position belongs in attention

An attention head forms a query for the current token and keys and values for candidate tokens. Queries compare with keys; the resulting weights mix the values. Without positional information or other order-dependent structure, this comparison cannot distinguish arbitrary reorderings. A causal mask supplies an ordering constraint, but it does not by itself encode a particular relative distance.

Absolute position embeddings add a position vector to a token representation. Relative biases add a distance-dependent term to attention scores. RoPE instead rotates query and key coordinates before taking their dot product. These are different ways of supplying useful position information, with different behavior when the context length changes.

RoPE in two dimensions

Group an even-dimensional head into coordinate pairs. Write the unrotated pair as \(q_j=(q_{jx},q_{jy})\), and similarly for \(k_j\). A rotation by angle \(\phi\) is

\[R(\phi)=\begin{pmatrix}\cos\phi&-\sin\phi\\\sin\phi&\cos\phi\end{pmatrix}.\]

At query position \(m\), rotate pair \(j\) by \(m\omega_j\); at key position \(n\), rotate by \(n\omega_j\). The dot product becomes

\[(R(m\omega_j)q_j)^\top R(n\omega_j)k_j=q_j^\top R((n-m)\omega_j)k_j.\]

Only the relative displacement remains in the rotation. The unrotated vectors still depend on token content and earlier layers. This construction and the standard frequency schedule come from Su et al., RoFormer.

A geometric ladder of frequencies

\[\omega_j=B^{-2j/d},\qquad j=0,\ldots,d/2-1.\]

Here \(d\) is head dimension and \(B\) is the frequency base. Adjacent frequencies have the constant ratio \(B^{-2/d}\). Their wavelengths, \(2\pi/\omega_j\), grow geometrically. High frequencies rotate quickly over nearby tokens; low frequencies change slowly over the same window. Calling a pair “slow” always depends on the distances under discussion.

The examples below use adjacent pair notation for readability. Qwen2.5’s actual 128-dimensional head uses split-half pairs \((j,j+64)\). A change in memory layout is harmless only if the model’s projections and rotations use the same pairing.

A finite sinusoidal score family

Set \(\Delta=n-m\). Expanding the rotation gives

\[s(\Delta)=\frac{1}{\sqrt d}\sum_j\left[A_j\cos(\omega_j\Delta)+B_j\sin(\omega_j\Delta)\right],\] \[A_j=q_{jx}k_{jx}+q_{jy}k_{jy},\qquad B_j=q_{jy}k_{jx}-q_{jx}k_{jy}.\]

The sine sign follows this particular rotation and displacement convention. Reversing displacement reverses the sine coefficient. The implementation is tested against direct rotations, including a two-dimensional example that catches this sign error.

For fixed content, every pair supplies one sinusoid. Across actual token pairs, the coefficients change: a trained head is not generally one fixed distance-only function.

What do 0, π/2, and π mean?

Write one term as \(r\cos(\omega\Delta-\theta)\), with \(r=\sqrt{A^2+B^2}\) and \(\theta=\operatorname{atan2}(B,A)\). This \(r\) is a query–key product amplitude. It differs from the radius of a key alone, which appears in the compression experiments.

Phase offsetContributionInterpretation
0\(r\cos(\omega\Delta)\)A local maximum at zero displacement; symmetric in either direction.
π/2\(r\sin(\omega\Delta)\)Zero at the reference point, but directional and position-dependent elsewhere.
π\(-r\cos(\omega\Delta)\)A local minimum at zero displacement; finite suppression, not exclusion.

“No preference at π/2” is therefore only a statement about the contribution at one point. A phase is not a global switch between attraction, indifference, and rejection. A causal mask also determines which directions are available.

Softmax mixes information

\[p_i=\frac{e^{s_i/T}}{\sum_k e^{s_k/T}},\qquad o=\sum_i p_i v_i.\]

This is weighted aggregation, as in Attention Is All You Need. A head need not classify one key as the winner. With two scores 2.0 and 1.9 at temperature one, weights are about 52.5% and 47.5%; both values contribute. Other heads can behave like sharp selectors. The task and value vectors decide which distribution is useful.

Adding a constant to every score changes nothing. Finite logits receive positive weights in exact arithmetic, so negative scores do not implement a hard mask. A small best-versus-runner-up margin is not inherently a failure.
