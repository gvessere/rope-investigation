# ROPE exploration

A personal exploration of RoPE through its connection to Fourier transforms.

[Read the blog](https://gvessere.github.io/rope-investigation/).

## Edit and preview

Edit `index.html` for prose and equations; `style.css` controls presentation.
Equations use native MathML, with their LaTeX source in each annotation. The site uses local JavaScript files for the plot viewer and phase-shift example; it has no remote scripts, fonts, or rendering dependencies.

Run `python3 -m http.server 8771` from this directory to preview locally.

## Regenerate every figure

Requires Python 3.9 or newer. From this repository's root:

```sh
python -m pip install -r requirements.txt
python code/figures.py
python -m unittest discover -s code -p 'test_*.py'
```

The pinned packages are NumPy 2.0.2 and Matplotlib 3.9.4.
`code/figures.py` contains every target function, fitting operation, and plot.
It generates `figures/dft-reconstruction.svg`, `figures/frequency-grids.svg`,
`figures/rope-shapes.svg`, `figures/results.json`, and `figures/examples.npz`.
No external data, model weights, or randomness are used to generate figures.
SVG dates are suppressed and IDs are stable. The array archive contains the
samples, predictions, frequencies, and fitted coefficients behind the plots.

The RoPE examples fit 256 scores using 64 geometric frequencies (128 real
coefficients), base 10000, no extra intercept, and ridge penalty 0.001. They
illustrate representational possibilities, not trained-model findings or
long-context performance. Displacement is query position minus key position;
positive values refer to earlier keys.

Tests check arbitrary real DFT reconstruction, the sine/cosine expansion against
explicit query/key rotations, the geometric ratio, and the fit's optimality
condition. GitHub Actions runs these checks and regenerates the figures before
deploying the static site.

## Original model plots and the dynamic viewer

The viewer in `index.html` and `explorers.js` displays all 70 plot pages based on the original data
from the four requested investigation PDFs, with query/key, view, and layer
selectors, previous/next controls, enlargement, and PDF downloads.
Dotted gray angular guides have been added at the union of multiples of π/4
and π/3 (including π/4, π/3, π/2, 2π/3, 3π/4 and their continuations around
the circle). Cartesian guides are labeled rays; phase guides are labeled
vertical lines. Original source hashes and current rendered-file hashes are
recorded separately in `data/observations/manifest.json`. The CSS preserves each image's aspect ratio.

The 56 NPZ files in `data/observations/` are **lossless layer splits** of the
original float32 amplitude/phase arrays: no token subsampling, rounding,
quantization, centering or density binning. Query shape: (28,12,768,64); key
shape: (28,2,2379,64). These saved activations suffice to regenerate the plots
without downloading model weights or rerunning inference.

```sh
python code/reproduce_observations.py --verify
python code/reproduce_observations.py --kind queries --view xy --page 0
python code/reproduce_observations.py --pdf
```

The last command regenerates all 70 PNG pages and all four PDFs. PDF metadata
(e.g. creation dates) may differ; plot data and rendering instructions are
preserved. Before angular guides were added, local verification with the pinned packages
reproduced representative query-Cartesian and key-phase pages pixel for pixel. `--verify` checks every data
chunk hash, shape, finite values, phase range, point count and amplitude-cap
count. The full dataset is about 170 MB and every file is below GitHub's 100 MB
limit. All original plot pages include every saved point; only the phase view's
0–40 amplitude cap clips points.

Provenance: original chat **ROPE investigation**, turns recorded in the manifest.
The model is Qwen/Qwen2.5-1.5B-Instruct. There are 16 prose excerpts from four
Project Gutenberg books, 48 saved queries per excerpt, and 2,379 body keys.
The metadata files retain sample positions, book/paragraph references, original
point-array hashes and original plot range summaries. Learned projection bias
is retained; known positional rotation was removed before plotting. Raw
query/key phase is not a relative query–key phase or causal evidence of shape
translation. No fresh model measurement is claimed here.

The phase-shift widget evaluates the same fitted coefficients from
`figures/shift-examples.json`, generated by `code/figures.py`, at displacement
minus the requested shift. It does not refit. It is a deterministic constructed
example, cropped to show only values from the original fit interval.

## Adjustable scales in the live viewer

The viewer draws **every retained saved point** onto a canvas directly from the
existing per-layer NPZ files. No data files are duplicated or regenerated.
`scatter-data.mjs` reads NumPy ZIP/NPY data using native gzip decompression with
ZIP CRC validation; `scatter-viewer.mjs` performs filtering and plotting.
`data/observations/palette.json` preserves the 64-color turbo palette and is
exported by `code/reproduce_observations.py`.

- The **Autoscale r to the 99th percentile per head** checkbox is on by default.
  It uses linear interpolation of sorted float32 radii with double-precision
  index/interpolation arithmetic, across all saved tokens and 64 pairs in the
  head, before applying the phase window. Ties can retain slightly more than 99%.
- Manual `r min` and `r max` apply the same limits to all shown heads. Editing
  either field turns autoscale off. A blank manual `r max` uses each head's
  complete range. **Show all points** resets the radial and phase filters.
- Phase bounds are entered in units of π. The Cartesian view always preserves
  equal x/y units and symmetric axes; radius filtering also omits points outside
  the selected radial interval that would otherwise fit in square corners.
- Each panel and the summary report how many original points remain visible.
  A head selector helps inspect an individual head. PNG export saves the current
  canvas. The PDF archive retains its published fixed scales.
- Layers load on demand; up to eight decoded layers are cached. First load
  requires native browser gzip decompression. If unavailable or loading fails,
  the fixed-scale image and PDFs remain available.

`node code/test_viewer.mjs` checks NPZ decoding, percentile calculations, full
and manual ranges, and phase-window counts against independent NumPy reference
values for every first-layer query and key head. The fixtures use float64
percentile arithmetic on the saved float32 values. These checks run in CI.
