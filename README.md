# ROPE exploration

A fresh start, beginning only with a description of Rotary Position Embeddings.

Website: https://gvessere.github.io/rope-investigation/

Edit `index.html` for the text and equations, and `style.css` for presentation. Equations use native MathML. There are no build dependencies or external scripts.

Preview with `python3 -m http.server 8771` from this directory.

The previous articles, experiments, and figures have been removed from the current branch. Earlier commits preserve the previous version.
