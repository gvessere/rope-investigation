RoPE navigator

The earlier pages looked at RoPE through equations and averaged plots. Here I wanted to follow individual tokens: which keys match a query before the final rotation, which remain afterward, and how each coordinate pair contributes to that change.

Start with a query point or a row in the key tables. Pin the selection, switch between before and after RoPE, and inspect the contribution bars. The attention profile shows individual keys, so the peaks and displaced matches remain visible rather than being averaged away.

Measurement scope and numerical audit

Saved input-text activations, not generated answer tokens. Query → key lists use the saved native top-10 keys from the complete causal history. Key → query lists rank only the 128 captured queries in this passage/head. Each attention percentage belongs to its query’s full causal softmax, so percentages across queries do not sum to 100%. High attention does not prove causal influence on the answer. Future keys are excluded.

Six query heads share one key head. Raw vectors include projection biases; positions and head labels are zero-based. Components of pair j are (j,j+64).

Pair contribution = rQ rK cos(φQ − φK + ω × age) / √128. Pair contributions use reconstructed rotations; their sum can differ slightly from native floating-point scores.
